# 产品设计文档 —— B站合集字幕提取器（MVP）

> 版本：v0.1（MVP 规划）　日期：2026-08-30

## 1. 背景与痛点

B站等视频网站的创作者会将系列视频归为"合集"。用户看完整个合集后，如果想把字幕留档（做笔记、喂给 AI 总结、离线阅读），只能在合集里一集一集地手动提取，合集越长操作成本越高。

本工具的目标：**输入一个合集链接，一次性提取该合集全部分集的字幕，输出为可直接阅读的 Markdown 文件。**

## 2. 目标与非目标

### MVP 目标（本期交付）

- 仅支持 **B站合集**：输入合集页 URL 或 season_id，解析出全部分集。
- 逐集获取字幕（CC 字幕 + AI 字幕），转换为 Markdown 落盘。
- 命令行工具，`--output` 指定下载目录（默认当前目录）。
- 单集失败不中断整体，结尾汇总三类结果：成功 / 下载失败 / 无字幕。
- 增量下载：文件已存在的分集自动跳过。

### v0.2 增补（已交付）

- 输入支持**合集内单个视频的链接或 BV 号**：自动通过 view 接口识别所属合集，再提取整个合集（原列为非目标，按用户需求转正）。视频不属于任何合集时明确报错。

### 非目标（本期不做）

- 其他平台（YouTube、西瓜、抖音等）——架构预留平台抽象接口，但不写实现。
- 图形界面 / 弹窗选目录。
- 无字幕视频的语音转写（ASR）。
- 时间轴输出、翻译、Markdown 以外的格式。
- b23.tv 短链解析（提示用户使用完整链接）。

## 3. 使用方式与输出规格

### 命令行示例

```bash
# 默认下载到当前目录（支持合集页 URL 或 season_id）
subtitle-cli <合集URL或season_id>

# 输入合集内单个视频的链接或 BV 号，自动识别并提取整个合集
subtitle-cli <视频URL或BV号>

# 指定输出目录
subtitle-cli <合集URL或season_id> --output D:/字幕/

# 传入 B站 Cookie（AI 字幕通常需要登录态，SESSDATA）
subtitle-cli <合集URL或season_id> --cookie "SESSDATA=..."
```

Cookie 属于敏感凭据：只通过命令行参数或环境变量传入，不写入代码、不进 Git。

### 输出结构

```
<output目录>/
└── <合集名>/
    ├── EP01 第一集标题.md
    ├── EP02 第二集标题.md
    └── ...
```

### Markdown 内容形态

纯文本正文：以分集标题作一级标题，字幕块按标点/时间间隔等简单启发式拼成自然段落，不含时间轴。目标是"通顺可读"，用于阅读、笔记和 AI 总结，不追求完美分段（后续迭代打磨）。

```markdown
# 第1集 视频标题

大家好，今天我们来聊一聊……
首先介绍一下背景……
```

## 4. 核心流程

1. **解析输入** → 识别 season_id（合集页链接 / season_id 直接解析；单视频链接或 BV 号经 view 接口反查所属合集）。
2. **获取分集列表** → 调合集接口（处理分页与 wbi 签名），得到每集的 BV 号、标题、序号；长合集（几十上百集）必须完整遍历。
3. **逐集获取字幕** → 调 player 接口拿该集可用字幕列表（CC + AI），选择并下载字幕 JSON；请求间加随机间隔，携带必要 Cookie。
4. **转换落盘** → 字幕 JSON 转纯文本段落，清洗 Windows 非法文件名字符，显式 UTF-8 写入 `.md`。
5. **结果汇总** → 输出成功 / 失败 / 无字幕三类清单，失败可重跑（配合增量跳过）。

## 5. 风险与对策

| 风险 | 对策 |
| --- | --- |
| AI 字幕接口需要登录态，未登录拿不到 | MVP 即支持 `--cookie` 输入；文档说明如何获取 SESSDATA |
| 部分视频无任何字幕（AI 字幕覆盖率有限） | 三分类汇总明确列出无字幕分集及原因，避免用户误判为工具故障 |
| B站接口随时变化（wbi 签名、风控、分页） | **动手前先花半天实测接口**，把当前可用性与依赖确认清楚；接口层单独封装便于后续修补 |
| 批量请求触发风控 | 随机间隔、控制并发为串行，失败重试带退避 |
| 字幕为创作者/平台内容 | 定位为个人学习用途的轻量工具，仅供个人使用 |

## 6. 技术方案与工程约定

- 语言与形态：Python + httpx/requests，命令行工具，规模控制在数百行。
- 接口层与转换层分离：字幕 JSON → Markdown 的转换是纯函数，用录制的接口响应 fixture 做单元测试，不依赖网络。
- 真实接口调用做成手动开关的集成测试，不进常规测试流程。
- Windows 兼容：文件名清洗、UTF-8 写文件。

## 7. 后续迭代方向（非本期）

- 更多平台（接口抽象已预留）。
- ASR 转写，覆盖无字幕视频。
- 可选的时间轴输出、其他格式。
- 段落拼接质量优化。
- 简单 GUI。
