# 开发计划 —— Obsidian 知识库版（v1）

> 版本：v1.0（依据 `PRD.md` v1.0 编制，可直接执行）　日期：2026-08-30
> 方法沿用上一轮实现会话（M0–M4 成版）的既定套路：**里程碑递进、纯函数先行、fixture 离线测试、每个里程碑 pytest 全绿后独立 commit**。里程碑编号从 M5 续起。

## 0. 总原则与执行纪律

1. **架构不动**：四层单向依赖（`bilibili/` 唯一网络边界 → `pipeline` → `converter`/`storage` → `cli`/`web`）。新增的 `notes`、`vault`、`migration` 三个模块**一律不做网络请求**；`migration.py` 甚至不 import `bilibili`（用 import 检查测试锁死，保证离线属性）。
2. **正文一字不动**：`converter.subtitle_to_markdown` 与清洗逻辑（`reviewer.clean_lines`）不改；属性头是在其成品外层包装。
3. **每个里程碑的完成标准**：`pytest` 全绿 + 独立 commit（AGENTS.md 约定）。集成测试仍走 `SUBTITLE_CLI_INTEGRATION=1` 手动开关。
4. 开工前一次性执行：`pip install -e ".[dev]"`；M8 新增 console script 后**重装一次**以注册 `subtitle-cli-migrate`。

## 2. 关键技术决策（实现前定死，避免中途摇摆）

1. **多P 判定**：`season_id.startswith("BV")` 即多P（`resolve_input` 的现有约定）。多P 时属性头**省略 `season_id` 键**，`url = https://www.bilibili.com/video/{bvid}?p={index}`；合集 url 不带参数。
2. **YAML 手写序列化**，不引第三方依赖：值含 `: `、`"`、`#`、`[`、`]`、换行或以特殊字符开头时用双引号包裹并转义；中文值不加引号。写 roundtrip 测试锁行为。
3. **索引页条目从磁盘实况生成**：重生成时 `glob("EP*.md")` 实际存在的文件 → 双链目标，**不用标题重算**，保证双链与文件名（sanitize 后）永远一致；别名用 `第N集 标题` 形式。无字幕/失败集自然缺席，历史遗留分集自然收录。
4. **迁移跳过标记**：frontmatter 存在且含 `fetched_by: subtitle-cli` 即「已迁移」。迁移补不出的字段（`bvid`/`url`）**写空字符串**，保证 schema 一致、Obsidian 属性面板可用。
5. **配置优先级**：CLI 参数 > `~/.subtitle-cli/config.json`。CLI/web 显式传入 vault 路径即写回配置（「配置一次」语义；配置文件不含敏感信息）。
6. **互斥**：网页同一时刻只允许一个后台任务（现有 `_lock` + `STATE["running"]`），迁移复用同一套任务线程与 `/api/run` 轮询。
7. **验收 13 的口径**：「不删除用户既有文件」指非空文件；现有 `run_collection` 清理**上次中断遗留的 0 字节空文件**属于自愈行为，保留并在测试注释中说明。

## 3. 里程碑

### M5 笔记层（纯函数，最先做、不接调用方）

**目标**：`PRD F2/F3` 的全部纯逻辑成型并可单测。

**任务**（新建 `src/subtitle_cli/notes.py`）：

- `episode_url(bvid: str, index: int, *, is_multi_p: bool) -> str`
- `build_episode_note(meta: EpisodeMeta, body_md: str) -> str`，其中 `EpisodeMeta`（pydantic）：`title`（一级标题文本）、`collection`、`season_id: str | None`、`bvid`、`episode_index: int`、`is_multi_p: bool`、`fetched_at: date`
  - frontmatter 键序固定：`title, collection, season_id(多P省略), bvid, episode, url, fetched_at, fetched_by, tags`；`fetched_by: subtitle-cli`；`tags: [B站字幕, <collection>]`
- `build_index_note(collection: str, season_id: str | None, entries: list[IndexEntry], fetched_at: date) -> str`，`IndexEntry = (filename_stem, alias)`；`type: index`、`episodes: N`、`updated` 属性头
- `parse_frontmatter(text: str) -> dict | None`（只支持本工具产出的简单形态：标量键 + 单层列表）
- `has_migration_marker(text: str) -> bool`
- `validate_meta(meta) -> list[str]`（缺失字段清单，供预览报告「属性头字段完整性」）

**测试**（新建 `tests/test_notes.py`）：字段齐全与键序快照；标题含 `:` `"` `#` 换行 的转义 + `parse_frontmatter` roundtrip；多P 省略 season_id 且 url 带 `?p=N`；索引页双链数量/别名；`has_migration_marker` 正负例。

**验收映射**：验收 1 的格式部分（结构层）。**提交**：`feat: obsidian note layer — frontmatter, index page and wikilinks (M5)`

### M6 vault 配置与检查

**目标**：`PRD F1` 的配置面 + `F5` 的检查逻辑。

**任务**（新建 `src/subtitle_cli/vault.py`）：

- `VaultConfig`（pydantic）：`vault: str = ""`、`subdir: str = "B站字幕"`
- `config_path() -> Path`（`Path.home() / ".subtitle-cli" / "config.json"`）
- `load_config(path=None) -> VaultConfig`：文件缺失/损坏 → 默认值，不抛
- `save_config(cfg, path=None)`：父目录创建 + 临时文件原子替换
- `collection_root(cfg) -> Path`：`<vault>/<subdir>`；`vault` 为空抛 `ValueError`（上层转提示）
- `check_vault(path: str, *, create: bool = False) -> VaultCheckStatus`：`ok / is_vault_root / writable / message / can_create` 四字段；不存在时 `create=True` 才创建；`.obsidian` 存在性决定 ✅/⚠️；写入能力用临时探针文件验证后清理

**测试**（新建 `tests/test_vault.py`）：roundtrip；损坏 JSON 回退；三态断言（tmp 目录有/无 `.obsidian`）；create 行为；`collection_root` 空 vault 报错。测试通过可选 `path` 参数注入 tmp，不碰真实 HOME。

**验收映射**：验收 4 的逻辑层。**提交**：`feat: vault config persistence and health check (M6)`

### M7 管线与 CLI 接入（vault 直写打通）

**目标**：`subtitle-cli <来源> --vault …` 端到端可用（`PRD F1/F2/F3/F7` 的 CLI 半边 + `F8` 回归）。

**任务**：

- `storage.py`：`write_markdown(path, content, *, overwrite: bool = False)`；`overwrite` 走 `"w"` 模式，默认行为（`"x"` + `FileExistsError`）不变
- `pipeline.py`：
  - `run_collection(..., note_mode: Literal["plain", "obsidian"] = "plain")`；obsidian 模式下成功集正文经 `subtitle_to_markdown` 后再包 `notes.build_episode_note`（`episode_heading` 不变）
  - 成功日志行 obsidian 模式改为 `EP01 已写入 vault：EP01 标题.md`；循环结束（obsidian）扫描合集目录实况生成索引页（`overwrite=True` 写入）+ 日志 `索引页已更新：《合集名》.md（N 集）`
  - `RunOutcome` 增字段：`output_dir: str = ""`、`index_path: str | None = None`、`note_mode: str = "plain"`；`summarize()` 在 obsidian 模式追加落点行 `已写入 vault：<output_dir>/<合集名>/`
  - `preview_first_episode(..., note_mode=...)`：预览 Markdown 带属性头；`format_preview` 追加「属性头字段完整性」行（`notes.validate_meta`）
- `cli.py`：`--vault PATH`、`--vault-subdir SUB`；`--vault` 给出时 `vault.save_config` 写回；vault 模式下 `output` 语义 = `collection_root(cfg)`；既无 `--vault` 又无配置文件 vault 且未给 `--output` → 报错退出码 2，提示「用 --output 或先 --vault 配置一次」

**测试**：`test_pipeline.py` 增 obsidian 模式组（复用现有 Mock client fixture）：属性头存在且正文与 plain 模式逐字一致；跳过集入索引、无字幕/失败集不入；二次运行索引仍完整；日志行断言。`test_storage.py` 增 overwrite 用例（含「索引页覆盖、分集文件仍拒绝覆盖」）。`test_cli.py` 增 `--vault` 端到端（tmp vault）、参数优先级、缺配置退出码 2。

**验收映射**：验收 1、3、5、11、12（CLI 面）。**提交**：`feat: write obsidian notes with per-collection index via --vault (M7)`

### M8 迁移（离线转换 + 独立命令）

**目标**：`PRD F4` 全量（`subtitle-cli-migrate`）。

**任务**（新建 `src/subtitle_cli/migration.py`）：

- `scan_collections(root: Path) -> list[CollectionScan]`：含 `.md` 的子目录各为一个合集（`name/dir/files/pending/already/unparsable`）；散落的根目录单文件收集进 `unparsable` 说明
- `parse_legacy_note(path: Path) -> LegacyNote | None`：文件名 `EP(\d+) (.+)\.md` 解析序号与标题；正文剥掉首个 `# ` 行后为 body；解析失败 → `None`
- `migrate_collection(scan, vault_collection_dir: Path, *, overwrite: bool, log) -> CollectionResult`：三分类 `migrated / skipped / failed(reason)`；每集 `notes.build_episode_note`（`bvid=""`、`url=""`、`collection=文件夹名`、`fetched_at=今天`）；结束生成索引页；目录不存在/不可写 → 整体 failed
- `migrate(root, vault_cfg, collections, *, overwrite, dry_run, log) -> MigrationOutcome` + `format_migration_summary()`（含缺失字段说明行）

**任务**（新建 `src/subtitle_cli/migrate.py`）：typer app：`source_dir` 位置参数、`--vault`、`--vault-subdir`、`--collections a,b`、`--overwrite`、`--dry-run`；退出码 0/1/2；`pyproject.toml` 注册 `subtitle-cli-migrate`（**改后重装**）。

**测试**（新建 `tests/test_migration.py`）：tmp 构造旧合集 → 全字段断言 + 索引页；二次运行全 skipped；`--overwrite` 重写且正文不变；`--dry-run` 零写盘（前后目录快照相等）；坏文件名/空文件计 failed；根目录散文件进说明；**离线性**：`assert "bilibili" not in sys.modules`（子进程 import 检查）。

**验收映射**：验收 7、8、9、10。**提交**：`feat: offline migration of legacy subtitles into vault notes (M8)`

### M9 网页后端

**目标**：`PRD F1/F4/F5/F6` 的 API 面（`web/server.py`）。

**任务**：

- `GET/POST /api/config`：读写 `vault.load_config/save_config`
- `POST /api/check-vault`：`{path, create}` → `check_vault` 结果
- `POST /api/migrate-scan`：`{dir}` → 合集清单（含 pending/already/unparsable 计数）
- `POST /api/migrate`：`{dir, collections[], overwrite}` → 后台线程；`STATE` 增 `kind: "extract" | "migrate"`，`/api/run` 原样轮询；迁移走 `migration.migrate`
- `POST /api/extract` 增 `vault`、`vault_subdir`：给了 vault → `output_dir = <vault>/<subdir>`、`note_mode="obsidian"`，并保存配置；demo 模式忽略 vault 参数（行为不变）
- `run_job` 分派两种任务；`STATE.files` 改为 `[{name, badge}]`（新写入/跳过/迁移），索引页置顶；汇总快照增 `obsidian_open: str | None`（`check_vault` 为 ✅ 时构造 `obsidian://open?vault=<名>&file=<subdir>/<合集名>/<合集名>`，路径段 `urllib.parse.quote`）
- `STATE["output_dir"]` 在 vault 模式存 `<vault>/<subdir>`，则 `/api/file` 现有白名单逻辑原样覆盖 vault（补越权测试）

**测试**（`test_web.py` 增）：config roundtrip；check-vault 三态；migrate-scan/migrate 全流程（tmp 旧目录 → vault 产物断言）；extract 带 vault 端到端；demo 不受 vault 参数影响；`/api/file` vault 模式越权 404；任务互斥 409。

**验收映射**：验收 4（API 面）、6（URI 构造）、14。**提交**：`feat: web API for vault config, health check and migration (M9)`

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 标题含 YAML 特殊字符（`:` `"` `#`）破坏 frontmatter | M5 手写转义 + roundtrip 测试锁死；宁过度引号不欠 |
| 双链目标与实际文件名不一致（sanitize 截断等） | 决策 3：索引条目从磁盘 glob 生成，不重算 |
| vault 路径加深导致 Windows 260 超限 | `TITLE_MAX_CHARS=60` 已保守；M7 增最长路径断言测试 |
| 配置文件写坏（进程中断） | 原子替换写（tmp + replace）；load 损坏回退默认 |
| `obsidian://` 中文路径编码 | `quote` 路径段；M9 测试断言 URI 可解析 |
| 迁移误伤用户其他 Markdown | 仅处理 `EP\d+ …\.md` 命名的文件，其余计 unparsable 不动 |
| 前端 JS 无自动化测试 | M10 仅静态断言；交互项全部列入 M11 冒烟清单 |

## 7. 执行顺序与预计节奏

M5 → M6 → M7 → M8 → M9 → M10 → M11，严格串行（每步依赖上一步产物）。M5/M6/M8 无网络依赖可随时验证；M7/M9 的真实链路验证需要 Cookie（可先跑 Mock/fixture 级测试，真实冒烟集中到 M11）。每个里程碑一次 commit，共预计 7 个 commit。
