# 多平台扩展计划 —— 播客 · 抖音 · 语音转写

> 版本：v0.1（2026-08-30）　状态：**第 1 步（播客）已实现**，后续步骤待用户确认
> 前置：`PRD.md`（v1.2 Obsidian 知识库版）已交付；本轮按用户要求"一步一步完善，动手前确认"推进。

## 0. 架构前提（已验证）

`pipeline.py` 的 `PlatformClient` 协议当初即为多平台预留：新增平台 = 新增一个客户端实现
（`resolve_input / list_episodes / fetch_subtitles`）+ `dispatch.py` 工厂分支。
笔记层（notes）、vault、索引页、网页、迁移全部复用，正文管线（converter/reviewer）一字未动。

现有平台分派（`src/subtitle_cli/dispatch.py`）：B站特征（bilibili.com / b23.tv / BV 号 /
纯数字）优先，小宇宙 / Apple / 其余 http(s) 链接按播客尝试，其余回落B站报旧版错误。

## 1. 关键调研结论（2026-08-30 实测）

| 结论 | 数据 | 对路线的影响 |
| --- | --- | --- |
| 中文播客 RSS 几乎没有现成文稿 | 热门中文节目抽样 40 个 feed，`podcast:transcript` 标签 **0 个** | 播客要全覆盖中文内容，最终必须靠语音转写（ASR） |
| Apple 自动逐字稿不支持中文 | [官方文档](https://podcasters.apple.com/zh-cn/support/5316-transcripts-on-apple-podcasts)语言列表无中文；抽样中文节目网页均无 transcriptUrl | Apple 网页逐字稿路线对中文内容无效 |
| Apple 节目链接可稳定反查 RSS | iTunes lookup 接口返回 feedUrl，实测可用 | 输入侧支持 Apple 链接，成本低 |
| 小宇宙网页端不公开 RSS | 节目页 HTML（含 __NEXT_DATA__）无 RSS 字段 | 小宇宙链接无法直接解析，引导用户从 App「复制 RSS 链接」 |
| 抖音无公开字幕 API | 社区方案均走第三方付费 API（TikHub 等）或浏览器插件 | 抖音字幕的现实路线 = 下载音频 + 本地 ASR |
| 本机网络环境 | 海外站点（如 podnews.net）连接超时 | 英文播客文稿路线在用户环境下可用性有限 |

**核心判断：抖音和中文播客殊途同归——"下载音频 → 本地 ASR 转写"是覆盖中文内容的唯一通用路线。**

## 2. 已实现：第 1 步 播客 MVP（本次交付）

- **输入**：RSS 地址（通用）、Apple Podcasts 节目链接（自动反查 RSS）；小宇宙链接给出 App 内复制 RSS 的指引
- **提取**：单集现成文稿（`podcast:transcript`），按 中文 > 格式标准度（VTT/SRT > JSON/TXT > HTML）选轨；支持 VTT/SRT/JSON/纯文本/HTML 兜底
- **编号**：按发布时间正序，最早的为第 1 集；单集页面链接写入属性头 `source`
- **落盘**：vault 模式默认 `<vault>/播客字幕/<播客名>/`（`--vault-subdir` 可改，B站与播客分目录互不影响）；标签为 `播客字幕` + 播客名；索引页不写 season_id
- **复用**：增量跳过、预览审查、三类汇总与退出码、清洗（无效行/重复行）、网页界面全部照常工作；播客输入不需要 Cookie
- **测试**：`tests/test_podcast_*.py`、`test_dispatch.py`、`test_pipeline_podcast.py`、`test_cli_podcast.py`；pytest 全绿；真实 feed（得意忘形）冒烟通过

**已知边界**：因中文播客几乎无现成文稿，当前版本对多数中文播客只会输出「无字幕 N 集」——
这不是缺陷而是数据源现状；补上 ASR（§3 第 2 步）后即可出正文。

## 3. 待确认的后续步骤（按建议顺序）

### 第 2 步：本地语音转写（ASR）兜底 【建议下一个做】

- **做什么**：无现成字幕/文稿时，下载音频（B站音轨 / 播客 enclosure）→ faster-whisper 本地转写 → 走既有管线出笔记
- **代价**：新增依赖 faster-whisper（首次运行下载模型约 0.5–1.5GB）；CPU 转写约等于音频时长的 0.3–1 倍时间，长合集/长播客耗时明显；有 NVIDIA 显卡可用 CUDA 提速数倍
- **收益**：中文播客、抖音、无字幕B站视频全部打通，是"全覆盖"的关键件
- **待确认**：要不要做？模型质量与速度的取舍（small 快 / medium 准）？

### 第 3 步：抖音视频字幕

- **做什么**：单个抖音视频链接 → 下载音频 → ASR → 笔记（不直接抓播放器 AI 字幕：接口有签名+风控，易失效）
- **范围待确认**：先只做单视频链接？UP 主主页作品批量放后面？
- **前置**：建议先完成第 2 步（复用同一转写能力）

### 备选小项（优先级低，随用随加）

- b23.tv 短链支持（解析 302 即可，纯B站侧）
- YouTube 字幕（yt-dlp 路线成熟；受用户网络环境限制，优先级最低）
- 小宇宙链接自动反查 RSS（用 iTunes 按节目名搜索，同名节目有误配风险，需确认后做）
- 播客单集级提取（当前输入节目链接 = 提取全部；按需加单集模式）
